# Weekly reports

One entry per week, newest at the top, written **during** that week. Five minutes
each. They are the record of how the project actually went, and they make your
final reflection almost write itself.

## Week 2 (September 14 to September 20, 2026)

**Done this week**
- Completed the grocery item form and pantry item form interactions.
- Added recipe creation, saved recipes, and recipe filtering.
- Added search, filtering, sorting, and grouped list views for pantry and grocery items.
- Connected checked grocery items to the pantry and added the grocery item count badge to navigation.
- Updated the README and weekly project documentation.

**In progress**
- Completing the meal plan screen beyond its current placeholder content.
- Replacing placeholder recipe content with finalized sample data and screenshots.
- Reviewing responsive spacing and visual consistency across the remaining screens.

**Blocked or stuck on**
- Persistence has not been added yet, so items created during a session are lost when the app restarts.
- The meal plan interaction still needs a defined data flow before it can be connected to recipes and groceries.

**Decisions made, and why**
- Kept the current prototype in local widget state so form and navigation behavior can be tested without introducing a storage dependency too early.
- Reused the same search, filter, sorting, and grouped-list patterns across pantry and groceries to keep the main workflows consistent.
- Moved completed grocery items into the pantry to reflect the real shopping workflow and make the two lists useful together.

**Hours spent, roughly:** ~25 hours

**Next week I will:**
- Build the meal plan data flow and add meals to specific days.
- Decide on and implement the first persistence approach.
- Capture final screenshots and continue preparing the demo video.

- Implemented the pantry item form with form fields and discard confirmation.
- Added search fields and filter menus for pantry and grocery items.

**In progress**
