## Screens

### Log In

Shows email and password fields and a sign-in action. The user enters credentials and signs in; success opens **Explore recipes**, while failure stays here with an error.

### Pantry

Shows pantry items and quantities or status. The user can add, edit, or remove an item. Add opens **Add pantry item**; selecting an item opens **Edit pantry item**; Remove opens **Alert dialog**. Save or cancel on either form returns here.

### Add pantry item

Shows fields for a pantry item's name, quantity, and related details. The user enters values and saves or cancels; both actions return to **Pantry**, with Save adding the item.

### Edit pantry item

Shows the selected pantry item's current values. The user edits and saves, cancels, or requests removal; Save or Cancel returns to **Pantry**, while Remove opens **Alert dialog**.

### Groceries

Shows grocery items and completion status. The user can add, edit, check off, or remove an item. Add opens **Add grocery item**; selecting an item opens **Edit grocery item**; checking it updates this list; Remove opens **Alert dialog**. Save or cancel on either form returns here.

### Add grocery item

Shows fields for a grocery item's name, quantity, and related details. The user enters values and saves or cancels; both actions return to **Groceries**, with Save adding the item.

### Edit grocery item

Shows the selected grocery item's current values. The user edits and saves, cancels, or requests removal; Save or Cancel returns to **Groceries**, while Remove opens **Alert dialog**.

### Meal plan (day view)

Shows meals planned for one date. The user can change the date, add a meal, or navigate elsewhere. Date opens **Date picker**; Add meal opens **Select recipe**; choosing a date returns here for that date.

### Meal plan (week view)

Shows planned meals across a week. The user can move between weeks, open a day, or navigate elsewhere; opening a day leads to **Meal plan (day view)** for that date.

### Meal plan (month view)

Shows planned meals across a month. The user can move between months, open a date, or navigate elsewhere; opening a date leads to **Meal plan (day view)** for that date.

### Select recipe

Shows recipes that can be added to the meal plan. The user selects a recipe or goes back; selecting one opens **Add meal to plan form**, while going back returns to the meal plan.

### Add meal to plan form

Shows the selected recipe and fields for its planned date or meal details. The user completes and saves the form or cancels; Save returns to the meal plan with the meal added, while Cancel returns to **Select recipe**.

### Explore recipes

Shows browsable recipe cards, search, and filters. The user can search, open a recipe, or set filters. Selecting a card opens **Recipe details**; Filters opens **Filter sheet**; navigation to saved recipes opens **My recipes**.

### Recipe details

Shows a recipe's image, description, ingredients, and instructions. The user can go back or add it to a meal plan. Back returns to the recipe list; Add to plan opens the meal planning flow for this recipe.

### My recipes

Shows the user's saved recipes and management controls. The user can open or add a recipe; selecting a card opens **My recipe details**, and Add opens **Add recipe, step 1**.

### My recipe details

Shows the selected saved recipe's details. The user can return to **My recipes**, edit it, or add it to a meal plan; Edit opens **Edit recipe, step 1**, and Add to plan opens the meal planning flow.

### Add recipe (steps 1–5)

The five-step form collects recipe information, ingredients, instructions, and other details. The user enters information, moves between steps, and saves or cancels; Next advances, Back returns to the previous step, Save adds the recipe and opens **My recipes**, and Cancel returns to the form's originating screen.

### Edit recipe (steps 1–5)

The five-step form shows the saved recipe's information, ingredients, instructions, and other details. The user edits values and moves between steps; Next and Back move through the form, Save returns to **My recipe details** with changes applied, and Cancel returns there without changes.

### Filter sheet

Shows available recipe filter choices. The user selects or clears filters, then applies or dismisses them. Apply returns to the originating recipe list with filters applied; dismiss returns without applying changes.

### Dropdown sheet

Shows selectable values for the field that opened it. The user chooses an option or dismisses the sheet. Choosing an option returns to the originating form with that value selected; dismiss returns with the value unchanged.

### Date picker

Shows a calendar. The user selects a date or cancels. Selecting a date returns to the meal plan for that date; Cancel returns to the previous meal plan date.

### Alert dialog

Shows a confirmation prompt before an item is removed. The user confirms or cancels. Confirm removes the item and returns to the screen that opened the dialog; Cancel closes the dialog and leaves the item unchanged.
